# HTML Forms

A beginner-friendly project focused on creating and structuring HTML forms.

## Overview

This project explores how HTML forms collect information from users through different input elements.

## Concepts Practised

- HTML form structure
- Input fields
- Labels and placeholders
- Buttons
- Form elements and attributes
- Basic CSS styling

## Built With

- HTML5
- CSS3

## Getting Started

Open `index.html` in your web browser to view the project.
